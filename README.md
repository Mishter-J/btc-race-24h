A cbBTC/USDC momentum bot for make.fun's 24-hour BTC trading race. It buys a sharp 5-minute upward surge (+75 bps) confirmed by a non-negative 15-minute return, then rides the move with a 60 bps trailing stop and a 120-minute max hold. Long only, one position at a time, full equity per trade. On the published dev window it nets +30.15 USDC over 2 round trips with a 1.4% max drawdown. All arithmetic is integer, no clock, no randomness — fully deterministic.

## Run it

```sh
node main.ts
```
